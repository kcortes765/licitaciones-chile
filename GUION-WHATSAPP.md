# Guion WhatsApp — IngenIA Licitaciones

Guion completo para el funnel de ventas por chat.
No improvisar. Copiar y adaptar con el nombre real de la empresa.

---

## ESTRUCTURA DEL FUNNEL

```
Paso 1: Mensaje inicial (ya generado en leads_verificados.xlsx)
  ↓ responde
Paso 2: Insight gratis por chat
  ↓ pide más
Paso 3: Demo 1 licitación por chat
  ↓ interesado
Paso 4: Cierre → $190K
  ↓ paga
Paso 5: Entrega PDF
  ↓ satisfecho
Paso 6: Upsell mensual → $490K/mes
```

---

## PASO 2 — Responden al primer mensaje

### Caso A: interés directo ("cuéntame más", "qué encontraste", "qué viste")

```
De las [N] licitaciones donde [EMPRESA] no fue adjudicada,
[X] las ganó el mismo competidor: [RIVAL].
Eso es el [X]% de sus derrotas contra un solo rival.

Eso no es mala suerte — es un patrón. Y donde hay
patrón, hay algo que [RIVAL] está haciendo distinto.

¿Le interesa que le muestre en qué licitaciones pasó
y qué tienen en común?
```

### Caso B: neutro o curioso ("¿de dónde sacas eso?", "¿qué eres tú?")

```
Los datos son públicos — vienen directamente de
Mercado Público / ChileCompra.

Analizo el historial completo de participación y
resultados de constructoras activas en Chile.
En el caso de [EMPRESA] hay un patrón interesante.

Si quiere, le cuento.
```

### Caso C: respuesta corta positiva ("dale", "ok", "qué más")

Ir directo al Paso 3 sin pedir permiso.

---

## PASO 3 — Piden la demo

### Trigger: "sí cuéntame", "¿qué licitación?", "¿qué se puede hacer?"

```
Perfecto. Páseme el código de una licitación donde
hayan participado, o si quiere le miro una de las
que tengo en el historial de [EMPRESA].

Le hago un mini análisis: qué pedían las bases,
quién ganó y con qué ventaja probable, y qué se
podría mejorar para la próxima.

Sin costo, por aquí mismo.
```

### Entrega del análisis (5-8 bullets, todo por chat)

Generar los datos con el pipeline antes de responder.

```
Revisé [NOMBRE CORTO DE LICITACIÓN] ([CÓDIGO]).

- Monto: $[X]M CLP. Tipo: [LP/LQ/LE]. Región: [X].
- Adjudicó: [RIVAL] con [oferta/criterio diferenciador].
- Criterio clave: [técnico/precio/plazo — cuál pesó más].
- Lo que probablemente definió el resultado: [observación concreta].
- Para la próxima licitación similar: [recomendación accionable].

Esto es solo una licitación. El diagnóstico completo
cubre todo el historial de [EMPRESA], sus competidores
principales y patrones de adjudicación.

Valor: $190.000 + IVA. ¿Le interesa verlo completo?
```

## PASO 4 — Cierre

### "¿Cuánto cuesta?" / "¿cuánto es?"

```
El diagnóstico completo es $190.000 + IVA.

Incluye PDF de 6 páginas con:
- Historial completo de postulaciones
- Posicionamiento vs el mercado
- Análisis de competidores que le han ganado
- Costo de oportunidad en pesos concretos
- Recomendaciones para las próximas licitaciones

¿Le cuadra?
```

### "Sí, ¿cómo pago?"

```
Transferencia a:

Banco: [BANCO]
Cuenta corriente: [NUMERO]
RUT: [RUT]
Nombre: Sebastián Cortés [o razón social si la tiene]
Email: sebastian.cortes.ing@gmail.com

En cuanto confirme, le preparo el diagnóstico.
Tiempo de entrega: 24 horas hábiles.
```

### Confirmación de pago recibido

```
Perfecto, recibido. Le tengo el diagnóstico
en [FECHA/HORA ESTIMADA].

Cualquier consulta mientras tanto, me avisa.
```

## PASO 5 — Entrega del PDF

```
Aquí está su diagnóstico: [LINK o archivo adjunto]

Un resumen de lo más importante:
- [Insight 1 del PDF]
- [Insight 2 del PDF]
- [Insight 3 del PDF]

Si tiene alguna duda o quiere que le explique
algún punto, me avisa y coordinamos.
```

Nota: no ofrecer llamada por defecto. Solo si el cliente la pide.

## PASO 6 — Upsell al servicio mensual

Momento ideal: justo después de entregar el PDF, cuando el cliente está satisfecho.

```
Una cosa más: esto que le mostré es una foto fija
del historial hasta hoy.

Si quiere que le monitoree las licitaciones nuevas,
le avise cuando aparezca una que calce con su perfil,
y le analice a los competidores en tiempo real —
eso es el servicio mensual.

$490.000/mes + IVA. ¿Le interesa que le cuente?
```

### Si dice "¿qué incluye?"

```
El servicio mensual incluye:

- Alertas semanales de licitaciones que calzan con
  su perfil (tipo, monto, región)
- Análisis de competidores activos en esas licitaciones
- Seguimiento de rivales clave (como [RIVAL])
- Soporte por WhatsApp para cualquier duda

Sin contrato largo — mes a mes. Si no le sirve, para.
¿Arrancamos?
```

## OBJECIONES

### "Es caro"

```
$190K es menos de lo que cuesta una hora de un
abogado de licitaciones. Y esto no es asesoría
legal — es inteligencia competitiva concreta.

Una licitación adjudicada de $96M hace que
$190K sea ruido de fondo.

¿Qué parte le parece cara — el precio o lo que incluye?
```

### "Lo veo después" / "Me avisa cuando..."

```
Sin problema. ¿Cuándo le queda bien que le vuelva
a escribir — en una semana o en dos?
```

Nota: fijar fecha concreta. Si no da fecha, seguir en 7 días.

### "¿Esto lo hace una IA?" / "¿Eres una máquina?"

```
Soy Sebastián Cortés, ing. civil. Uso herramientas
de análisis automatizado para procesar los datos
de Mercado Público — igual que un financiero usa
Excel, pero para licitaciones.

El análisis y las recomendaciones las reviso yo
antes de entregárselas.
```

### "Ya sabemos leer bases" / "Ya lo hacemos nosotros"

```
Seguro. La diferencia es que esto no es leer su
propia base — es ver lo que hacen sus competidores
en licitaciones donde ustedes también estuvieron.

¿Saben qué criterio usó [RIVAL] para ganarles
esas [X] licitaciones?
```

### "No licitamos seguido"

```
Entiendo. ¿Tienen pensado postular a algo próximamente?

El diagnóstico igual sirve para entender el mercado
antes de entrar, no solo para evaluar lo que ya pasó.
```

### "¿Cómo sé que funciona?"

```
El mini análisis que le hice recién es exactamente
lo mismo que hace el diagnóstico completo, pero
para una sola licitación.

Si eso le pareció útil, el diagnóstico completo
es eso multiplicado por todo su historial.
```

## SEGUIMIENTO

### No responde en 48 horas (follow-up 1)

```
Sebastián Cortés nuevamente.

Le mandé el análisis de [EMPRESA] hace un par de días.
¿Tuvo oportunidad de verlo?
```

### No responde al follow-up (cierre del lead)

Esperar 7 días. Luego:

```
Entiendo que puede estar ocupado. Si en algún
momento le interesa el análisis, aquí estoy.

Que les vaya bien en las próximas licitaciones.
```

No insistir más. Marcar como "inactivo" en el CRM.

### Responde semanas después

Retomar desde donde quedó, sin explicar el delay.

```
Hola [nombre], claro que sí. ¿Quiere que retomemos
con el análisis de [EMPRESA] o hay algo nuevo
que le interese revisar?
```

---

## REGLAS GENERALES

1. Nunca mandar PDF gratis. El valor gratis es texto en el chat.
2. Nunca mencionar score, cluster, modelo, pipeline, ML.
3. Nunca afirmar causalidad — usar "sugiere", "podría indicar", "se observa".
4. Nunca llamar para vender. La venta ocurre por chat.
5. Llamada solo si el cliente la pide explícitamente.
6. Generar los datos del paso 3 con el pipeline ANTES de responder.
7. Un mensaje a la vez. Esperar respuesta antes de enviar el siguiente.
