## CÓMO USAR ESTE CONTEXTO

Pega esto al inicio de tu conversación con cualquier IA, seguido de tu pregunta
específica. Ejemplos:

### Para analizar una base:
```
[PEGAR ESTE CONTEXTO]

Necesito analizar esta base de licitación. Detecta hallazgos críticos,
normas desactualizadas, y riesgos de descalificación.

[PEGAR BASE DE LICITACIÓN]
```

### Para generar outreach:
```
[PEGAR ESTE CONTEXTO]

Genera un mensaje de WhatsApp para esta empresa basado en este hallazgo:
- Empresa: [nombre]
- Licitación: [código]
- Hallazgo: [descripción]
```

### Para redactar oferta técnica:
```
[PEGAR ESTE CONTEXTO]

Redacta la sección de metodología de trabajo para esta licitación:
[PEGAR REQUISITOS DE LA BASE]
[PEGAR DATOS TÉCNICOS DEL CLIENTE]
```

### Para pricing o negociación:
```
[PEGAR ESTE CONTEXTO]

El cliente [empresa] me dice [objeción]. ¿Cómo respondo?
Su contexto: [tipo empresa, tamaño, cuánto licitan]
```
