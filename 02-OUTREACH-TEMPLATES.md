# Templates de Outreach - Licitaciones Chile

## Contexto para IA
Cuando uses estos templates con Claude/Gemini, pásale:
- Nombre de la empresa
- Licitación específica (código, nombre, monto, fecha cierre)
- Hallazgo que detectaste en la base
- Nombre del contacto (si lo tienes)

## Template para análisis gratis (primera entrega)

### Estructura del informe:
```
ANÁLISIS ESTRATÉGICO DE BASE DE LICITACIÓN
==========================================

Licitación: [código] - [nombre]
Mandante: [organismo]
Monto estimado: [CLP]
Fecha cierre: [fecha]
Fecha apertura técnica: [fecha]

1. RESUMEN EJECUTIVO (5 líneas máximo)
   Qué se pide, qué implica, riesgo general.

2. REQUISITOS CRÍTICOS DE ADMISIBILIDAD
   - Lo que te descalifica si no lo tienes.
   - Documentos obligatorios.
   - Garantías exigidas.

3. HALLAZGOS ESTRATÉGICOS
   ⚠️ [Hallazgo 1]: [Norma/requisito que cambió o es fácil de omitir]
   ⚠️ [Hallazgo 2]: [Riesgo contractual oculto]
   ⚠️ [Hallazgo 3]: [Punto donde se pierde puntaje técnico]

4. NORMATIVA EXIGIDA
   - Lista de NCh y normas referenciadas
   - Estado de actualización de cada una
   - ⚠️ Normas con cambios recientes

5. RÚBRICA DE EVALUACIÓN TÉCNICA
   - Criterios y ponderación
   - Dónde se ganan más puntos
   - Dónde pierden la mayoría de los postulantes

6. RECOMENDACIONES
   - Acciones concretas para maximizar puntaje
   - Riesgos a mitigar antes de presentar
```

## Objeciones Frecuentes y Respuestas

### "Ya sabemos leer bases"
```
"Seguro. La pregunta es: ¿tienen tiempo para leer
300 páginas de cada base y cruzarlas contra las
1,200 normas NCh vigentes? Yo lo hago en 20 minutos."
```

### "Es muy caro"
```
"$490K al mes. Si ganan UNA licitación más al año
gracias a esto, ¿cuánto vale eso? Estamos hablando
de contratos de cientos de millones."
```

### "¿Y si no funciona?"
```
"La primera base se las analizo gratis. Si no les
sirve, no hay compromiso. Si les sirve, conversamos."
```

### "Eres estudiante"
```
"Sí, y por eso cobro la mitad de lo que cobraría
una consultora. Pero el análisis es el mismo —
basado en la normativa vigente y las bases reales."
```
